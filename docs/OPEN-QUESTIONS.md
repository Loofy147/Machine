# Open Questions

These questions are intentionally unresolved. They are research targets, not requirements disguised as facts.

## Operation

1. What is the minimum executable primitive set?
2. Is `Recompose` fundamental, or can it emerge from simpler operations?
3. Can a machine discover useful operation combinations without a semantic task objective?
4. What makes one state transition more useful than another without importing a human goal model?

## Representation

5. When should the machine change representation rather than operate longer on the existing representation?
6. Can representations themselves be learned as executable structures rather than passive descriptions?
7. What makes a relation operational rather than merely descriptive?

## Continuity

8. What minimum persistent state is required for experience to alter future operation?
9. Which state should survive, which should decay, and which should be isolated?
10. Does coherent identity improve cumulative adaptation, or merely create path dependence?

## Learning

11. Can learning occur as changes in operation policy while the machine remains continuously active?
12. How can we distinguish useful adaptation from accidental drift?
13. What evidence shows that a changed operation regime was learned rather than memorized?

## Exploration and closure

14. How can the system detect that its own operation regime is becoming self-confirming?
15. How can it search for relevant information or operations that its current regime does not know to value?
16. How much destabilization is useful before exploration becomes noise?

## Resource allocation

17. Is computation allocation a consequence of operation policy rather than a primary attention mechanism?
18. Can a machine learn when to spend more computation without defining depth as an objective?
19. Can operation value be estimated from downstream state change rather than a fixed reward?

## Generality

20. Is generality better described as capability composition than general intelligence?
21. What is the smallest reusable operational substrate that transfers across unrelated environments?
22. Does a general machine need a general world model, or can it construct local models as needed?

## Validation

23. What experiment would falsify the claim that recomposition is a core source of generalization?
24. What experiment would show that the whole architecture is merely an elaborate search procedure?
25. What experiment would show that an LLM is unnecessary for the core capability?
26. What experiment would show that a small LLM is useful as one machine operation rather than as the machine itself?
