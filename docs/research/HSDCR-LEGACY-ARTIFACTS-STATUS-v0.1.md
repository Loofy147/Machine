## Interpretation rule

A statement in a legacy artifact is current only when it is consistent with the current index, full finding, related-research baseline, and gap-closure matrix.

In particular, none of the following older formulations should be read as proof of architectural novelty:

- a named semantic atom;
- a component being structurally necessary;
- a provider collision;
- a composition model;
- a successful CI run.

The current evidence vocabulary controls promotion.
