# HSDCR Working Label Status v0.1

Status: **NON-NORMATIVE / WORKING LABEL**

Recorded: 2026-09-28

## Definition status

"HSDCR" currently means only:

> Highly Sensitive Decentralized Contribution Repository

It is a temporary label for the object of investigation.

It does **not** currently assert that the object is:

- a protocol;
- a standard;
- a product;
- a repository implementation;
- a decentralized network;
- a new architecture;
- or a new computational capability.

## Why the label is retained

The label is useful because the current investigation repeatedly touches three observable requirements:

1. sensitivity to small/early changes or signals;
2. independent contribution loci;
3. repository-like durable state and lineage.

These requirements are hypotheses/working requirements, not yet a frozen specification.

## Naming rule

Do not allow the name to determine the ontology.

In particular:

- "Highly Sensitive" does not mean secret or privacy-classified.
- "Decentralized" does not imply decentralized authority or storage until separately established.
- "Contribution" is not assumed to mean commit, PR, issue, event, or actor activity.
- "Repository" is not assumed to mean Git repository or object store.

## Promotion gate

The label may be upgraded only after:

1. atomic capability ledger is complete enough to support a closed comparison set;
2. neighboring architecture embedding tests identify the residual;
3. required distinctions survive those tests;
4. a minimal state/transition model can be written without importing an existing system's ontology by name;
5. independent implementation or experiment verifies the resulting model.

Until then:

	ext{HSDCR} = 	ext{working label}
