# Formal Specification & Verification Report: Machine Substrate $\mathcal{M}$ — Rev 2.1

> **Evidence legend.** **[P]** proved (proof or proof sketch given) · **[T]** tested by the accompanying randomized suite (ID, trials) · **[M]** measured (environment in §7; median, IQR/range where stated) · **[N]** not tested here.
> Every quantitative statement below is generated by the accompanying scripts (`machine_substrate_artifacts.zip`, `bidir_harness_v3.zip`); nothing is hand-entered.
> **Rev 2.1** adds literature grounding (§3.3, §3.4, §8) and real-graph scheduling measurements; it corrects the §3.3 bound (transition-count form) and withdraws the Rev 2 advice to balance bidirectional search by frontier work (§3.4).

Notation: $n=|S|$, $k=|\Sigma|$, $E=|\mathrm{dom}\,\delta|$, $\deg^-(u)=|F(u)|$.

## 1. Machine Substrate Definition

$$\mathcal{M} = (S, \Sigma, \delta, \mathcal{R}, \mathcal{C})$$

* **$S=\{0,\dots,n-1\}$** — finite state set, dense integer ids.
* **$\Sigma=\{0,\dots,k-1\}$** — finite action alphabet.
* **$\delta: S\times\Sigma \rightharpoonup S$** — *partial* deterministic transition function. $E\le nk$; $\delta$ is total iff $E=nk$. Stored as an $n\times k$ table (forward evaluation is one indexed read).
* **Labeled predecessor fiber** $F(u)=\{(s,a)\mid \delta(s,a)=u\}$, so $\sum_u \deg^-(u)=E$.
  The *unlabeled* set $\mathrm{Pred}(u)=\{s\mid \exists a:\delta(s,a)=u\}$ satisfies $\sum_u|\mathrm{Pred}(u)|\le E$, strictly when parallel edges exist. The substrate stores the **labeled** fiber.
* **$\mathcal{R}=(\delta\text{-table},\ \mathcal{R}^{-1})$**, with $\mathcal{R}^{-1}$ stored as CSR arrays
  * `offs[0..n]`, `src[0..E-1]`, `act[0..E-1]`; $F(u)=\{(\texttt{src}[i],\texttt{act}[i])\mid \texttt{offs}[u]\le i<\texttt{offs}[u{+}1]\}$;
  * optional **per-action index** `aoffs[0..nk]`, `asrc[0..E-1]`; $F_a(u)=\{s\mid\delta(s,a)=u\}$ is the bucket $u\cdot k+a$.
* **Invariants** (checked by `validate_csr`) **[T C1]**
  I1 `offs` monotone, `offs[0]=0`, `offs[n]=E` · I2 $\delta(\texttt{src}[i],\texttt{act}[i])=u$ for every $i$ in fiber $u$ · I3 every defined $(s,a)$ appears exactly once across all fibers · I4 entries sorted by $(s,a)$ inside a fiber.
* **$\mathcal{C}$** — word-RAM cost model, word size $\Theta(\log(n+E))$; primitives in §2.
* **Scope.** Deterministic $\delta$ (nondeterministic relations are out of scope), dense ids, static arcs unless P-07 is used.

```
Offline:  δ-table ──( counting sort, 3 passes )──> R⁻¹ = (offs, src, act [, aoffs, asrc])   Θ(n + E) time and space
                                                          │
Online:   u ∈ S ──( offs[u], offs[u+1] )──────────────────> F(u)      O(1) entry + O(deg⁻(u)) iteration
```

**Space.** $4(n{+}1)+4E+E$ bytes for `int32` offsets/sources and `uint8` actions — **[M]** exactly **1 200 004 B = 1.144 MiB** for $n=50\,000,\ k=4,\ E=200\,000$. Including the forward table (`int32`, $4nk$ B) the substrate totals 2 000 004 B = 1.907 MiB.

### Theorem 1 — Output-sensitive predecessor expansion **[P]**

> For every state $u$, expanding the predecessors of $u$ costs $\Theta(1+\deg^-(u))$ with $\mathcal{R}^{-1}$, and $\Omega(E)$ in the worst case without any index (with $\delta$ accessible only by probes). Consequently the per-step advantage is $E/(1+\deg^-(u))$: it is independent of $n$ *given* $\deg^-(u)$, and large only when $\deg^-(u)\ll E$.

*Proof.* Upper bound: $F(u)$ is the slice `[offs[u], offs[u+1])`: two reads plus one read per entry. Lower bound with the index: the $\deg^-(u)$ entries must be produced. Lower bound without an index (exact enumeration): an adversary answers every probed $\delta(s,a)$ with a value $\ne u$; any unprobed pair could equal $u$, so all $E$ pairs must be probed. $\square$

*Corollary 1.* Over a set $Z$ of expanded states, $\sum_{u\in Z}(1+\deg^-(u)) = |Z|+E_{\mathrm{in}}(Z)\le n+E$, where $E_{\mathrm{in}}(Z)$ counts edges with target in $Z$.
*Corollary 2 (hubs).* $\deg^-(u)$ can be $\Theta(E)$; the "$\ll nk$" regime does not hold there. **[M]** In the benchmark system the top hub holds 6.7 % of all edges (operation ratio 14.8×, §4.2).

### Theorem 2 — Build **[P]**

Counting sort: one pass to count in-degrees ($E$ reads), a prefix sum ($n$), one scatter pass ($E$ writes) is $\Theta(n+E)$ time/space. Scanning $\delta$ in $(s,a)$ order and scattering stably yields I4.

## 3. Verified Algorithmic Usabilities

```
                               ┌── Backward reachability / basins : μZ.(U ∪ Pre(Z))              needs F(u)
                               ├── Retrograde value propagation    : V(v) ← min c(v,a)+V(u)       needs F(u)
Substrate M ──> fibers ────────├── DFA minimisation (Hopcroft)     : splitter preimages           needs F_a(u)
                               ├── Bidirectional search            : forward δ + backward F       needs F(u)
                               └── Reactive-game attractor (CPre)  : predecessor counters         needs F(u), consistent multiplicity
```

| § | Algorithm | Bound with the substrate | Verified |
| :-- | :-- | :-- | :-- |
| 3.1 | Backward basin $Z^*=\mu Z.(U\cup\mathrm{Pre}(Z))$, $\mathrm{Pre}(Z)=\bigcup_{u\in Z}\mathrm{Src}(F(u))$ | $\Theta(\lvert Z\rvert+E_{\mathrm{in}}(Z))$ after the $\Theta(n+E)$ build | **[T C3]** 400 systems: fiber BFS (loop and vectorised) == per-node scan == layered fixpoint |
| 3.2 | Retrograde value propagation, costs $c\ge 0$ | $\Theta(E\log n)$ (binary heap), $\Theta(E+n\log n)$ (Fibonacci); $\Theta(n+E)$ for unit costs or DAGs | **[T C4]** == Bellman value iteration on 400 systems; **[M]** relaxations $=E$ exactly |
| 3.3 | DFA minimisation (Hopcroft) | $O(E\log n)$ for partial $\delta$ ($=\Theta(k\,n\log n)$ when total) [1]; **requires the per-action index** $F_a(u)$ | **[T C5]** == Moore on 200 DFAs (107 with merges); **[M]** §4.4 |
| 3.4 | Bidirectional search (BFS layers; Dijkstra with scheduling rules) | see below | **[T C6]** 2 000 BFS pairs × 3 policies == BFS distance; **[T]** 8 Dijkstra variants optimal on 6 837 runs; **[M]** §3.4, §4.3 |
| 3.5 | Player-0 attractor (controllable predecessor) | $\Theta(n+E)$ with counters | **[T C7]** 400 games == fixpoint |

**3.1 Backward reachability.** A full-scan baseline needs $\Omega(E)$ per expanded state (Theorem 1), hence $\Theta(|Z|\cdot E)$ for a per-node scan and $\Theta(d\cdot E)$ for a layer-synchronous scan ($d$ = number of layers). The advantage therefore depends on which baseline is meant (§4.3): $\approx|Z|$ against the per-node scan, only $\approx d/2$–$d$ against a layered scan.

**3.2 Retrograde propagation.** On settling $u$, relax every $(v,a)\in F(u)$: $V(v)\leftarrow\min(V(v),\,c(v,a)+V(u))$. This is Dijkstra on the reverse graph and needs $c\ge0$; the total number of relaxations is exactly $E_{\mathrm{in}}(\text{settled})\le E$, the heap adds the logarithmic factor.

**3.3 DFA minimisation.** Hopcroft's algorithm asks for $\{v\mid\delta(v,a)\in B\}$ per splitter $(B,a)$. With only the mixed fiber $F(u)$ every such query scans all actions' entries, inflating the work by $\approx(k+1)/2$ (§4.4). The bound is stated in the number of transitions: Valmari and Lehtinen give $O(|\delta|\lg|Q|)$ for partial transition functions [1], which is $\Theta(k\,n\log n)$ when $\delta$ is total; their grouping of transitions by label is a counting-style bucketing pass rather than a comparison sort [1] — the same idea as the counting-sort build of the per-action index (P-08). Paige–Tarjan is the algorithm for *nondeterministic* transition relations; it is outside this substrate's deterministic $\delta$ and **[N]** is not tested here.

**3.4 Bidirectional search.** *Unweighted (layer-synchronous).* Terminate after completing the first layer in which the frontiers meet (then $\mathrm{dist}=\min_v d_f(v)+d_b(v)$ over that layer — proof: before the layer no node is in both visited sets, so $D\ge i+j+1$, and any meeting in the new layer has value $\ge D$ while the node at forward-distance $i{+}1$ on a shortest path realises $D$) **[P]**. The classical "$b^d\to 2b^{d/2}$" holds up to saturation: unidirectional expansion is bounded by $n$.

*Weighted (Dijkstra).* Three classical selection rules exist — Dantzig (alternate whole vertices), Nicholson (side with the smaller next key), Pohl (side with fewer open vertices) — and Haeupler et al. prove that none of them is instance-optimal in edges accessed, whereas alternating single **edge** relaxations is, on positively weighted multigraphs [2]. Stop when $\mathrm{top}_f+\mathrm{top}_b\ge\mu$ and update $\mu$ on every relaxation whose target has a finite tentative distance on the other side; an extra "other endpoint already closed" guard in early versions of [2] was an error, fixed in the errata. In the edge-granular form a side may be mid-vertex, so its lower bound must include that vertex's key (a stopping bug of exactly this kind was caught by the random-multigraph test here).

**[T]** All 8 variants (5 whole-vertex rules, equal-work by vertex, equal-work by edge with two stopping rules) return optimal costs on 5 656 random directed-multigraph runs (parallel edges, self-loops, isolated vertices) and 1 181 structured runs; the 5 shared rules reproduce the earlier harness exactly on 1 350 runs.
**[M]** Edge scans, weights $1..9$, 60–150 random pairs per graph (bootstrap CIs and Holm-corrected tests in the research note):

| Graph | $n$, max deg | Bidir (Pohl) / forward-only scans | min-key / Pohl | alternate / Pohl | equal-work (edge) / Pohl | work-aware / Pohl |
| :-- | :-- | --: | --: | --: | --: | --: |
| Router-level Internet | 192 244, 1 071 | 0.010 | **29.8×** (19.4–45.0) | 1.10 | 1.03 | 1.01 |
| PGP trust network | 10 680, 205 | 0.051 | **6.6×** (5.5–7.8) | 1.25 | 1.00 | 0.98 |
| Political blogs | 1 490, 351 | 0.052 | **3.9×** (3.1–4.7) | 0.96 | 0.98 | 1.01 |
| US power grid | 4 941, 19 | 0.336 | 1.12 | 1.04 | 1.03 | 0.99 |
| Directed hub multigraph (substrate generator, 3 seeds) | 20 000, max in-degree 5 277–5 349 | 0.024 | 1.63 | 1.00 | 0.97 | 0.98 |
| Clustered bottleneck (density-asymmetric) | 600 | 0.397 | 2.55 | 1.83 | 1.23 | 0.99 |

Pohl's rule is within 4.2 % of the best rule on every graph; min-key can be catastrophic on heavy-tailed graphs (worst router-graph instance 675× the per-instance best); the whole-vertex alternation penalty is specific to strong degree asymmetry between the two sides; vertex- and edge-granular equal-work rules agree on average, but the edge-granular one has the smallest worst-instance regret on 4 of 6 datasets (e.g. 1.20× vs 5.29× for Pohl on the hub multigraph) — consistent with the worst-case guarantee of [2] and with the observation in [4] that min-cost interleaving can run one direction for long stretches once its frontier enters a dense region. A degree-aware rule (open-set degree sum) improves on Pohl by at most 1.9 % (significant on two graphs only: −1.3 % clustered, −0.7 % power grid), so Rev 2's advice to balance by frontier work is withdrawn as unsupported; heap length is as good as the exact open count (no significant difference on any graph; point estimates within 3.4 %).
*Model dependence.* In the adjacency-list query model with degree and neighbour queries in both directions, bidirectional Dijkstra is instance-optimal on positively weighted multigraphs [2]; on simple graphs the ratio is constant for undirected order-oblivious inputs but can be $\Theta(\lceil m/n\rceil)$ for directed ones [3]. The substrate's labeled fiber makes parallel actions parallel edges (multigraph regime); de-duplicated fibers correspond to the simple-graph regime, where $m/n\le k$ here.

**3.5 Attractor.** For an existential state $v$ add it when any successor is in $Z$; for a universal state decrement a counter per fiber entry and add it at zero. Multiplicity must be consistent: labeled fibers with out-degree counters, or de-duplicated fibers with #distinct-successor counters. **[T C7]** Mixing them (de-duplicated fibers with out-degree counters) returned a wrong attractor in 64 of 400 games.

## 4. Empirical Results

**System.** $n=50\,000$, $k=4$, total $\delta$, $E=200\,000$; 50 attractor hubs (Zipf-1 weights) receive 30 % of the edges. **[M]** in-degree mean 4.0, p99 7, **max 13 475 (6.7 % of $E$)**; **3 011 states (6.0 %) have an empty fiber**; 2 138 parallel edges ($\sum|\mathrm{Pred}|=197\,862<E$). Basin queries use targets whose backward basin covers ≥ 90 % of $S$ (a random target is trivial 6 % of the time). Correctness suite **[T]**: C1–C7 pass, 400 randomized systems each (C5: 200 DFAs; C6: 2 000 pairs).

### 4.6 Dynamic updates (P-07) **[M]**

Hash-indexed fibers (a `set` per state): **0.63 µs per arc update** over 200 000 mixed redefine/undefine updates; resulting fibers equal a fresh rebuild and I1–I4 hold. One numpy rebuild (16.9 ms) equals ≈ 26 900 updates. Deleting from the top-hub fiber: 35.1 µs with list-backed fibers versus 0.061 µs set-backed (575×).

## 5. Architectural Selection & Production Guidelines

```
                                    Which regime are you in?
                                                  │
        ┌───────────────────┬─────────────────────┼───────────────────────────┐
        ▼                   ▼                     ▼                           ▼
  Arcs change online   Python, static       Compiled, static          Memory-bound (E large)
                       δ                    δ                         9 B/edge + 4 B/state
                                                                            (1e9 edges ≈ 9 GB)
        │                   │                     │                           │
  Hash-indexed fibers  SciPy CSR + csgraph   Compact CSR arrays        Symbolic relational
  0.63 µs/update,      2.15 ms basin,        1.07 ms build,            product (BDD/ZDD) [N]
  ≈10–17× CSR memory   1.15 MiB              1.15 ms basin, 1.14 MiB
```

1. **High-performance verification tools:** compact CSR (`int32` offsets/sources, `uint8` actions): 9 B/edge + 4 B/state, best cache behaviour; add the per-action index if the workload includes partition refinement.
2. **Dynamic systems:** hash-indexed fibers; rebuild the CSR when a batch exceeds ≈ $0.13\,E$ arc updates (26 900 updates ≈ one numpy rebuild at $E=200\,000$ in this Python realisation; the ratio shifts with the implementation).
3. **Hub-dominated systems:** when $\max\deg^-\gtrsim E/15$, single hub expansions are only 15–30× cheaper than a scan (and slower than a vectorised scan in interpreted code); vectorise or bitset the frontier expansion.
4. **Very large systems:** the memory arithmetic above is exact for the CSR layout. Symbolic form: $\mathrm{Pre}(Z)(s)=\exists a,s'.\ R(s,a,s')\wedge Z(s')$ — the characteristic function of $\mathcal{R}^{-1}$ is the forward relation with variable roles exchanged, so no separate inverse structure is needed. **[N]** BDD/ZDD behaviour is not benchmarked here; no state-count thresholds are asserted.

## 7. Reproducibility

* Environment: Python 3.12.3, NumPy 2.4.4, SciPy 1.17.1, gcc `-O2`; Intel Xeon @ 2.10 GHz, 1 shared vCPU. Timings vary run to run on shared hardware; C results are reported over 5 seeds, Python results as medians of 5 runs (IQR shown).

* Files: `substrate_lib.py` (reference implementation), `test_correctness.py` (C1–C7), `bench.py` (§4 measurements), `substrate_bench.c` (machine-level), `substrate_results.json` (all numbers above).
