# Substrate Interpreter v0

Small CEK-style interpreter built from the Machine abstract model: State + Operation + Transition + Control.

This experimental substrate provides object-language lexical closures, recursive computation via LetRec, explicit control/environment/continuation/store state, persistent machine data, an S1 generic-readable-state contract, an S2 indexed-relation-access contract, and separate offline representation accounting.

This is an experimental substrate, not yet the canonical Machine interpreter.
